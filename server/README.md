# Сервер синхронизации

Нужен только для варианта «Свой сервер». Для Supabase и облачного диска сервер не требуется.

Это один файл на чистом Node.js — ни одной сторонней библиотеки, ставить нечего.
Нужен Node.js 18 или новее.

## Запуск

```
cd server
node server.js
```

Сервер скажет адрес и ключ доступа. Ключ он придумывает сам при первом запуске и
кладёт в `server/data/key.txt`. Свой ключ задаётся так:

```
DREVO_KEY=мой-пароль PORT=8080 node server.js
```

В программе: **⚙ Настройки → Синхронизация → Свой сервер**, вписать адрес и ключ,
нажать «Проверить связь».

## Где что лежит

```
server/data/tree.json      дерево целиком
server/data/media/         фотографии, документы, аудио, видео
server/data/history/       40 последних версий дерева, на случай ошибки
server/data/key.txt        ключ доступа
```

Резервная копия — это просто копия папки `server/data`.

## Запуск на домашнем компьютере

Так родственники будут видеть обновления, пока компьютер включён.

**Windows.** Создайте `старт.bat` рядом с `server.js`:

```bat
@echo off
set DREVO_KEY=мой-пароль
node server.js
pause
```

Чтобы сервер был виден из интернета, нужен либо белый IP с пробросом порта на роутере,
либо туннель — например, `cloudflared tunnel --url http://localhost:8080`: он выдаёт
готовый адрес с https, ничего настраивать не надо.

**Linux.** Через systemd, чтобы сервер поднимался сам:

```ini
# /etc/systemd/system/drevo.service
[Unit]
Description=Семейное Древо
After=network.target

[Service]
WorkingDirectory=/opt/drevo/server
Environment=DREVO_KEY=мой-пароль
Environment=PORT=8080
ExecStart=/usr/bin/node server.js
Restart=always
User=drevo

[Install]
WantedBy=multi-user.target
```

```
sudo systemctl enable --now drevo
```

## Про https

Браузер разрешает микрофон, уведомления и вход по отпечатку только на `https://`
(и на `localhost`). Варианты:

- **cloudflared** — проще всего, https из коробки, бесплатно
- **Caddy** — сам получает сертификат Let's Encrypt, конфигурация в две строки:
  ```
  drevo.мойдомен.ru {
      reverse_proxy localhost:8080
  }
  ```
- **nginx + certbot** — если он у вас уже стоит

## Сервер отдаёт и саму программу

Положите папку `server` внутрь папки с программой — и по адресу сервера откроется
«Семейное Древо». Тогда отдельный хостинг не нужен: один адрес и для программы,
и для синхронизации.

## Что умеет

| Запрос | Что делает |
|---|---|
| `GET /api/health` | проверка связи: сколько персон и файлов в хранилище |
| `GET /api/tree` | забрать дерево |
| `PUT /api/tree` | записать дерево (предыдущая версия уходит в `history`) |
| `GET /api/media/:id` | забрать файл |
| `PUT /api/media/:id` | записать файл |
| `DELETE /api/media/:id` | удалить файл |

Ко всем запросам нужен заголовок `X-Drevo-Key` с ключом доступа.

## Безопасность

Ключ один на всех — он разграничивает «свои и чужие», а не родственников между собой.
Роли и права на отдельные записи живут в самой программе.

Записи с замком приходят на сервер **уже зашифрованными** (AES-256-GCM). Ключ выводится
из пароля дерева на устройстве и на сервер не попадает: даже получив доступ к папке
`data`, прочитать такие файлы нельзя.

Ограничения: дерево не больше 64 МБ, один файл не больше 256 МБ. Правятся в начале
`server.js`, переменные `MAX_TREE` и `MAX_FILE`.
